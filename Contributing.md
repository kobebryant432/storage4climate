Feel free to contribute to the S4C wiki!

# How to contribute

1. Clone the wiki repository - https://github.com/VUB-HYDR/storage4climate.wiki.git.
2. Create a fork of the repository
3. Push your changes to your forked repository
4. Create a pull request to the main repository

Currently it is NOT possible to:
- Edit the wiki directly on GitHub
- Push changes without creating a pull request (and a fork) which needs to be approved
